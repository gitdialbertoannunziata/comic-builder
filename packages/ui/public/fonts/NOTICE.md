# Font di test

`ComicNeue-Regular.ttf` — [Comic Neue](https://github.com/crozynski/comicneue), licenza **OFL-1.1** (vedi `OFL.txt` in questa cartella).

Usato dal pacchetto `@comic-builder/lettering` per i test di misurazione reale dei glifi (§8.1 del piano). Non è una decisione sul font di default per i nuovi progetti (§14.8, ancora aperta) — è solo il font con cui i test esercitano `opentype.js` su metriche vere invece che su stime.
